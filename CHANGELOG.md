## 0.1.0

First release.

- `NumericText` — a number that rolls between values, reflowing as it grows and shrinks.
- `RollingText` — the same transition over an arbitrary string, split by character or by word.
- `NumericTextFormat` — plain, integer, currency and percent formats with explicit separators,
  plus `NumericTextFormat.custom` for any formatter you already have.
- Reduced-motion support, forced roll direction, edge fade, and a second colour for the
  fraction span.
